The trials

Sixteen Echoes

Each shows the move in GitGud, then the same in the terminal. Hover the marked words for their meaning.

Echo I Basics

First commit

Your edits start in the working tree. You stage what belongs together into the index, whole files or single hunks, then record it as a commit.

Spoken in the terminal
$ git status            # what changed
$ git add -p            # stage hunk by hunk
$ git add recipes.md    # or a whole file
$ git commit -m "feat: sell mana potions"
Echo II Basics

Branch out

A branch is just a movable label on a commit. Create one and HEAD follows it: new commits move that branch forward, while main stays where it was.

Spoken in the terminal
$ git switch -c feature/mana   # create + check out
$ git add shop.js
$ git commit -m "feat: sell mana potions"
$ git log --oneline --graph --all
Echo III Basics

Stash

Half-done work, and main needs a fix now? A stash puts your uncommitted edits aside and leaves the working tree clean. Switch branch, fix, come back, then pop the stash: your edits are back.

Spoken in the terminal
$ git stash -u              # -u: new files too
$ git switch main
$ git commit -am "fix: open every day"
$ git switch feature/mana
$ git stash pop
Echo IV Integrate

Fast-forward

When main is an ancestor of your branch, there is nothing to combine: git just slides the main label up to your branch. That's a fast-forward: no merge commit, the history stays a straight line.

Spoken in the terminal
# before: A─B ← main       after: A─B─C─D ← main, feature/mana
#              ╲C─D ← feature/mana
$ git switch main
$ git merge --ff-only feature/mana
Echo V Integrate

True merge

When both branches got new commits, they have diverged. Merging them creates a merge commit with two parents, which joins both histories.

Spoken in the terminal
$ git switch main
$ git merge feature/mana
Merge made by the 'ort' strategy.
$ git log --oneline --graph
Echo VI Integrate

See the conflict coming

Both branches changed the same line, so merging them stops on a conflict. GitGud tells you before you merge, right in the menu. The merge waits while you choose the result in the merge editor; continuing records the merge commit.

Spoken in the terminal
$ git merge-tree --write-tree main feature/mana  # predict
$ git merge feature/mana
CONFLICT (content): Merge conflict in shop.js
$ git add shop.js        # once edited
$ git merge --continue
Echo VII Integrate

Rebase onto

Instead of merging, rebase replays your branch's commits on top of main. The changes are the same but the commits are new, with new SHAs, and the history is a straight line.

Spoken in the terminal
$ git switch feature/mana
$ git rebase main
Successfully rebased and updated refs/heads/feature/mana.
Echo VIII Integrate

Cherry-pick

Need one commit of another branch, not the rest of it? Cherry-pick copies its change onto your branch as a new commit, with a new SHA. The other branch stays as it is.

Spoken in the terminal
$ git switch main
$ git cherry-pick 5c1e8a2   # fix: health potions cost 5
$ git log --oneline --graph --all
Echo IX Team play

Sync with the remote

Push uploads your commits to origin. Fetch downloads your teammates' commits without touching your files, and pull also brings them into your branch, from its upstream.

Spoken in the terminal
$ git push -u origin main   # -u: remember the upstream
$ git fetch                 # update origin/main only
$ git status
Your branch is behind 'origin/main' by 1 commit
$ git pull                  # fetch + merge
Echo X Second chance

Reword

A typo in an old commit message? Reword it. That commit and the ones after it are rewritten, so do it before you push, or force push afterwards.

Spoken in the terminal
$ git commit --amend          # the last commit only
$ git rebase -i HEAD~2        # an older one:
  reword 3f2a1c9 feat: sell mana potoins
  pick   9be04d2 feat: mana costs more
Echo XI Second chance

Fixup

Forgot a file in a past commit? Stage it and make it a fixup of that commit: it melts into the commit, keeping its message. A squash does the same but combines the messages.

Spoken in the terminal
$ git add recipes.md
$ git commit --fixup=3f2a1c9
$ git rebase -i --autosquash 3f2a1c9~
Echo XII Second chance

Squash

Three commits for one feature, two of them "wip"? Select them and squash them: one commit holding all their changes, with the message you write. Do it before you push.

Spoken in the terminal
$ git rebase -i HEAD~3
  pick   3f2a1c9 feat: sell mana potions
  squash 9be04d2 wip
  squash c71d0e4 wip: forgot the recipe
Echo XIII Mini-boss

Reorder, through a conflict

Moving a commit runs an interactive rebase. When two commits edit the same lines, it stops on a conflict. Pick a side, then continue. Careful: during a rebase, ours and theirs are swapped.

Spoken in the terminal
$ git rebase -i HEAD~3   # swap the two pick lines
CONFLICT (content): Merge conflict in potions.txt
$ git checkout --theirs potions.txt  # your commit
$ git add potions.txt
$ git rebase --continue  # or --abort
Echo XIV Second chance

Undo anything

Dropped the wrong commit? Git's reflog remembers every place HEAD has been, so a committed change is never really lost. GitGud's undo button reads it for you.

Spoken in the terminal
$ git reflog
8c41d07 HEAD@{0}: rebase (finish): returning to refs/heads/main
9be04d2 HEAD@{1}: commit: feat: mana costs more
$ git reset --hard HEAD@{1}
Echo XV Agents

Agent in its own worktree

A linked worktree is another working tree of the same repository, on its own branch. New starts Claude on your task in one, named after it: the agent edits and commits there, while main and your files stay untouched. The Agents section shows when it needs you; the log shows its commits, ready to review.

Spoken in the terminal
$ git worktree add -b agent/fire-potions \
    .claude/worktrees/fire-potions
$ cd .claude/worktrees/fire-potions
$ claude "Sell fire potions, 20 gold each"
Echo XVI Final boss

Lord Reflog

He remembers every commit you abandoned. Face him with two agents working at once, each in its own linked worktree. Once both are done, fast-forward main to the first one's branch, then merge the second through their conflict. Fall, and his reflog brings you back. (In GitGud, ↑↑↓↓←→←→BA summons him.)

Spoken in the terminal
$ git worktree add -b agent/fire-potions …
$ git worktree add -b agent/elf-discount …
$ git merge --ff-only agent/fire-potions
$ git merge agent/elf-discount
CONFLICT (content): Merge conflict in shop.js

Lost words every word the trials use
working tree
The files as they are on your disk, edits included.
index
Also called the staging area: what the next commit will hold.
stage
Put a change into the index: git add.
stash
Uncommitted edits put aside, leaving the working tree clean, until you pop them back.
hunk
One block of changed lines in a file's diff.
commit
A snapshot of the project, with a message, an author and its parent commits.
SHA
A commit's id, a hash of its content, e.g. 3f2a1c9. Changing a commit gives it a new SHA.
branch
A movable label pointing to a commit. Committing moves it forward.
HEAD
Where you are: usually the branch you have checked out.
ancestor
A commit you reach by following parents back from another one.
fast-forward
Moving a branch label forward to a descendant commit. Nothing to combine, so no merge commit.
diverged
Two branches that each have commits the other lacks.
merge commit
A commit with two parents, joining two histories.
rebase
Replaying commits on top of another commit, which creates new commits.
cherry-pick
Copying one commit's change onto your branch, as a new commit.
interactive rebase
A rebase where you edit the list of commits first: reorder, reword, squash, fixup or drop them.
remote
Another copy of the repository, e.g. on GitHub.
origin
The default name of the remote you cloned from.
upstream
The remote branch your local branch tracks, e.g. origin/main for main.
push
Upload your commits to the remote.
fetch
Download the remote's new commits, updating origin/* only. Your branches and files don't move.
pull
Fetch, then merge (or rebase) the upstream into your branch.
reword
Change a commit's message.
fixup
Fold a commit into an earlier one, keeping the earlier one's message.
squash
Fold a commit into an earlier one, combining both messages.
conflict
Two changes to the same lines that git can't combine on its own: you choose the result.
ours / theirs
The two sides of a conflict. In a merge, ours is your branch. In a rebase it's swapped: ours is the base you replay onto, theirs is your commit.
linked worktree
Another working tree of the same repository, checked out on its own branch, in its own folder.
agent
An AI coding CLI, such as Claude Code, that edits files, runs commands and commits for you.
reflog
Git's log of every place HEAD and your branches have been. The way back from any mistake.
Lord Reflog
When the branch is deleted and the commit cast into darkness, one shall remain who remembers. His name is spoken only once: git reflog. His price: ninety days, then oblivion.
